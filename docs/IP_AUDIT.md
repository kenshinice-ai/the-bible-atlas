## 3. 条目内引号 —— **本次唯一的发现,已修**

规范禁止「引号包裹的台词出现在 event 文本里」。扫描发现 **9 处**中文字段使用 `「」`,其中 **3 处包住了角色的话**:

| `obi-wan-tells-luke-of-his-father` | 「被维达害死了」 | **违规**,读作台词引用 → 改为间接引述「说父亲死于维达之手」 |
| `mace-windu-confronts-palpatine` | 「我可以教你」 | **违规** → 改为「那个愿意教他的承诺」 |
| 关系 穆迪→阿纳金 | 「心中有恐惧」 | **违规** → 改为「委员会认定他心中有恐惧」 |

另 6 处是概念强调(「传承」「相信」「来不及」「获得」「预见到却救不了」「像父亲那样」),本身不违规,但**一并去掉了括号**——理由是「条目文本中不出现任何引号」是机器可以永远返回零的检查,而「只保留非台词的那些」需要人对每一处反复判断。这个不变量比六对括号值钱。
