# 欧洲古典音乐史 Atlas

本目录保存欧洲古典音乐史独立 profile 的策展、数据与实施蓝图。

- `EUROPEAN_CLASSICAL_MUSIC_HISTORY_ATLAS_BLUEPRINT.md`：产品范围、信息架构、人物关系、乐器体系、代表性乐谱片段与自产合成声音方案、数据模型和验收门禁。
- `ECM_1_SCHEMA_API_ASSET_DESIGN.md`：ECM-1 schema、API contract、profile capability、WAV 资产和跨 work 约束评审结果。
- `GATE2_FOUNDATION_CURATORIAL_LIST.md`：48 人物、72 曲目、20 风格、24 乐器、16 机构、80 关系和 28 片段的冻结清单。
- `IMPLEMENTATION_CHECKLIST.md`：按 Gate 推进的执行清单；未通过前一 Gate，不进入下一阶段。

当前状态：**Foundation 实现、乐谱/声音资产、前端接入与 Cloudflare Pages production 发布已完成；公开线上浏览器 UI 验收仍受本环境 Browser URL policy 阻断，HTTP/JSON/资产门禁已通过。**
