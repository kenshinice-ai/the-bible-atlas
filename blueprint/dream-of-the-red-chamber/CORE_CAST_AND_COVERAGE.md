# 《红楼梦 Atlas》核心人物与内容覆盖

- 状态：`draft`
- 日期：`2026-08-15`
- 注意：人物范围为产品策展候选，不是文学排名

## 1. 收录原则

核心人物不是按“知名度前 20”简单排列，而按以下覆盖目标组合：

1. 情感核心；
2. 家庭与礼法权力；
3. 大观园同辈网络；
4. 丫鬟、照护与主仆关系；
5. 经济与阶层；
6. 贾府内外部观察；
7. 能形成明显关系阶段；
8. 能测试多种关系方向和不对称性。

## 5. 重要性不等于节点大小的唯一依据

节点大小可切换：

- 编辑重要性；
- 当前焦点关系数；
- 当前章回活跃度；
- 权力中心性；
- 照护中心性；
- 中介中心性。

默认采用“编辑重要性 + 当前焦点相关度”，不公开一个看似客观的总排名。

## 6. 章回覆盖模型

### 6.1 版本层

候选分层：

- `core_80`：前八十回关系基线；
- `continuation_40`：后四十回 continuation layer；
- `edition_commentary`：特定版本、脂评或研究说明；
- `editorial_synthesis`：本站编辑归纳。

### 6.2 章回带

| 章回带候选 | 叙事功能 | 产品用途 |
|---|---|---|
| 1–5 | 世界、命运与家族入口 | 人物身份、家族结构、主题预告 |
| 6–18 | 荣宁二府与大观园建立 | 权力、空间和群体形成 |
| 19–36 | 情感与日常关系高密度区 | Phase 1 重点互动事件 |
| 37–63 | 诗社、群体生活与秩序运作 | 群体网络、友情、竞争、照护 |
| 64–80 | 关系破裂与家族衰败加速 | 清退、死亡、冲突与退出 |
| 81–120 | 续书层 | 独立开关，不与 core_80 静默合并 |

章回带只是导航层，不替代逐回证据。

## 7. 两阶段覆盖策略

### Phase 1：前八十回

第一阶段以 `core_80` 为完整工程边界。实施仍可按章回带分批推进，但发布前应明确报告前八十回中已审核与未审核的章回，不用代表性切片冒充全覆盖：

1. 每位核心人物至少 3 条关键关系；
2. 每条一级核心关系至少覆盖形成、变化、结果中的两个阶段；
3. 先完成各章回带的代表性垂直切片，再逐步补齐前八十回；
4. 每个已宣布完成的章回做到 100% 互动事件审核；
5. 未审核章回标为 `not_yet_audited`，不能默认“无关系变化”。

### Phase 2：后四十回

第二阶段单独处理 `continuation_40`：

- 不与 Phase 1 同批 seed 或同一完成率报告；
- 使用同一人物身份，但关系 phase、互动和证据独立；
- 新增人物只在后四十回工程中按必要性纳入；
- UI 继续保留版本层开关和分轨显示；
- Phase 2 完成不反向改变 Phase 1 的文本判断。

## 8. 覆盖统计

发布报告分别统计：

- 核心人物数；
- 上下文人物数；
- canonical relationships；
- relationship phases；
- interaction events；
- evidence links；
- 已审核章回 / 冻结范围章回；
- core_80 / continuation_40 覆盖；
- 中文 / 英文 published 覆盖；
- disputed / pending / excluded 数量。

不得只用“已有多少条边”表示内容质量。
