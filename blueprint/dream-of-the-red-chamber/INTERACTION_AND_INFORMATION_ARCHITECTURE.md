# 《红楼梦 Atlas》交互与信息架构

- 状态：`draft`
- 日期：`2026-08-15`

## 1. 统一探索状态

候选 URL 状态：

```ts
interface RedChamberExploreState {
  locale: "zh-CN" | "en";
  view: "focus" | "compare" | "full" | "table" | "scene";
  focus: string | null;
  compare: string | null;
  chapterStart: number;
  chapterEnd: number;
  continuationVisible: boolean;
  lens: "all" | "kinship" | "affection" | "power" | "care" | "conflict";
  group: string | null;
  relationId: string | null;
  interactionId: string | null;
  evidenceLayer: "text" | "all";
}
```

所有列表、关系图、章回播放器、场景图和 drawer 从同一状态派生。语言切换保留其他字段。

## 2. 主导航

建议只保留五个一级入口：

1. 关系；
2. 人物；
3. 章回；
4. 场景；
5. 资料。

“事件”不作为一级 tab，而在章回与关系详情内显示为互动事件。

## 3. 关系主舞台模式

### 3.1 Focus

- 默认模式；
- 中心 1 人；
- 第一圈 6–12 个直接关系；
- 第二圈仅显示路径中介或当前章回关键人物；
- 点击外围人物平滑重心；
- 按 `Enter` 打开人物详情，按 `Space` 固定/取消固定；
- 支持“只看与此人有关的关系表”。

### 3.2 Compare

- 选择 A 与 B；
- 显示共同人物、独有关系、共同事件和结构差异；
- 两侧人物固定，其他节点按共同/独有分区；
- 不提供价值判断式胜负结论。

### 3.3 Full

- 仅桌面默认开放；
- 初始显示群体聚合；
- 放大到核心人物，再到全部已筛选人物；
- 边标签仅 hover、focus 或选中时出现；
- 提供框选、搜索定位和重置。

### 3.4 Table

- 与图等价；
- 列：人物 A、关系、人物 B、章回范围、主要维度、状态、证据数；
- 可按当前焦点、章回、facet、方向和强度排序；
- 作为键盘和 screen reader 的首要替代视图。

### 3.5 Scene

- 显示叙事空间节点，而非现实地图；
- 选择场景后显示当前章回在场人物和互动事件；
- Phase 1 可只做节点拓扑，不做精细平面图。

## 4. 章回播放器

### 4.1 控件

- 上一回 / 下一回；
- 播放 / 暂停；
- 速度 0.5× / 1× / 2×；
- 章回带跳转；
- 当前回标题与摘要；
- “只显示本回变化”开关；
- continuation layer 开关。

### 4.2 播放语义

每次推进只更新：

- 新出现人物；
- 新形成关系；
- 关系 phase 变化；
- 结束或转化关系；
- 当前互动事件；
- 当前场景。

不应在每一回重新随机布局。已有节点保持空间连续性，新节点从相关群体附近进入。

### 4.3 Reduced motion

- 取消节点飞入和路径描画；
- 直接切换状态；
- 使用文本摘要：“本回新增 2 条关系，1 条关系进入冲突阶段”；
- 不自动播放。

## 5. 关系显微镜

关系 drawer / 右侧阅读器分为：

1. **摘要**：双方、主要 facets、当前 phase；
2. **维度**：双向 affection/trust/power/dependency/conflict；
3. **阶段**：按章回排列；
4. **互动**：关键 interaction events；
5. **证据**：短引文、章回定位、来源；
6. **版本**：core_80 / continuation_40 / commentary；
7. **路径**：此关系在双方网络中的作用。

## 6. 人物详情

人物详情不使用“生日、死亡年份”模板。优先显示：

- 姓名、别名、称谓；
- 家族/群体；
- 身份与处境；
- 当前章回状态；
- 关系圈；
- 关系维度分布；
- 关键互动；
- 居住/活动场景；
- 来源与版本说明。

## 7. 搜索

搜索范围：

- 人物本名、别名、称谓；
- 关系标签；
- 互动事件标题；
- 章回标题与编号；
- 场景；
- 群体。

搜索结果必须带上下文：

```text
紫鹃
人物 · 林黛玉照护网络 · 8 条关系
```

不能只返回一个名字。

## 8. 空状态

- 未选人物：“选择一位人物，查看其关系圈。”
- 当前章回无变化：“本回没有已审核的关系阶段变化。”
- 无英文翻译：“英文内容尚未发布；保留中文原文定位。”
- 未审核：“此章回尚未完成互动审核，不代表没有关系变化。”
- continuation 关闭：“当前只显示前八十回关系基线。”

## 9. 响应式

### ≥1280

- 左人物轨道 240–280px；
- 中关系舞台弹性占满；
- 右阅读器 360–420px；
- 章回播放器固定底部 120–160px。

### 768–1279

- 左人物轨道折叠为搜索 + chips；
- 右阅读器使用 overlay drawer；
- 关系舞台保持至少 560px 高。

### <768

- 单列；
- 默认 focus 模式；
- 章回控件为底部 compact bar；
- 详情全屏 sheet；
- full graph 需要明确二次确认；
- 关系表可作为默认辅助模式。

## 10. 键盘交互

- `/` 聚焦人物搜索；
- `[` / `]` 前后章回；
- `Space` 播放/暂停（输入控件聚焦时除外）；
- `Esc` 关闭 drawer 或取消 compare；
- `Enter` 打开选中节点；
- 方向键在焦点人物的关系列表中移动；
- 所有快捷键必须有帮助面板且允许关闭。

## 11. 关键微交互

- hover 只预览，不改变 URL；
- click/select 才写入 URL；
- 章回播放期间 URL 更新节流；
- 选择关系时突出双方和共同事件，其他节点降到 12–18%；
- 选中节点有形状、描边和文字三重提示；
- 不使用持续漂浮、纸屑、花瓣或无意义视差。
